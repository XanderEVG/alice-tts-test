# alice-tts-test

Локальный сервис Text-to-Speech для Яндекс.Станции (Mini) без белого IP.

Запускается на вашем сервере, использует **только исходящие** соединения к API Яндекса.
Никаких пробросов портов, туннелей и платных облаков.

---

## Что умеет

- Озвучивать произвольный текст через Яндекс.Станцию Mini
- HTTP API (`POST /api/tts`) — можно дёргать из `curl`, скриптов, Node-RED, Home Assistant
- Автоматическое обнаружение колонки в аккаунте
- Работа в Docker, авторестарт, переживание перезагрузки сервера
- Готовая точка интеграции в Home Assistant (REST Command)

## Архитектура
┌──────────────────┐ исходящий HTTPS ┌────────────────────┐
│ Ваш сервер │ ───────────────────► │ API Яндекса │
│ alice-tts-test │ (белый IP не нужен)│ quasar.yandex.ru │
│ :5000 (локально)│ └─────────┬──────────┘
────────▲─────────┘ │
│ curl / HA / Node-RED ▼
локальная сеть ┌────────────────────┐
│ Яндекс.Станция │
│ Mini (в облаке) │
└────────────────────┘


Ключевой момент: **входящие соединения не требуются**. Сервер сам стучится в Яндекс,
Яндекс сам «стучится» в колонку. Поэтому отсутствие белого IP — не проблема.

---

## Требования

- Ubuntu 22.04+ (или любая другая Linux)
- Docker + docker-compose
- Яндекс.Станция Mini, привязанная к вашему Яндекс ID
- Сервер и колонка в одной локальной сети (не обязательно, но так надёжнее)

## Быстрый старт

### 1. Клонировать и подготовить конфиг

```bash
git clone git@github.com:XanderEVG/alice-tts-test.git
cd alice-tts-test
cp config.json.example config.json
```

2. Получить токен
```bash
python3 get_token.py
```

Скрипт выдаст ссылку → открыть в браузере → залогиниться → скопировать весь URL
из адресной строки после редиректа → вставить в консоль. Скрипт вытащит access_token.
Токен вписать в config.json в поле yandex_token.
