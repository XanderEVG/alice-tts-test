# qwen.md — контекст проекта для ассистента

> Этот файл — память проекта. Читать первым. Не содержит секретов, коммитится в репозиторий.

## Мета

- **Проект:** `alice-tts-test`
- **Владелец:** локальный сервер, Ubuntu 22.04+, Docker установлен
- **Цель чата:** Home Assistant (глобально) → сейчас: этап до HA
- **Язык общения:** русский
- **Уровень собеседника:** IT-специалист, спокойно воспринимает код, Docker, API.
  Пояснения «для чайников» не нужны, но аббревиатуры и неочевидные ID — расшифровывать.

## Задача

Научить Яндекс.Станцию **Mini** воспроизводить текст, который генерирует локальный сервер.

## Жёсткие ограничения

1. ❌ Белого (публичного) IP **нет**
2. ❌ Платить за внешний сервер / VPS / туннель **нельзя**
3. ✅ Исходящий интернет с сервера есть
4. ✅ Колонка и сервер в **одной локальной сети**
5. ⏳ Home Assistant планируется, но **пока не установлен** → решение не должно от него зависеть

## Принятые решения (не пересматривать без причины)

| # | Решение | Почему |
|---|---------|--------|
| 1 | **Путь 1**: сервер сам ходит в API Яндекса, входящие не нужны | Обходит отсутствие белого IP без платить и без туннелей |
| 2 | API Яндекса: `quasar.yandex.ru/glagol/*` | Внутренний API управления станциями, используется официальным приложением |
| 3 | `client_id = 23cabbbdc6cd418abb4b39c32c41195d` | ID официального приложения Яндекс.Станции, имеет нужные scopes для управления колонками. Свой client_id через oauth.yandex.ru **не подойдёт** — не будет прав на Quasar |
| 4 | Стек: Python + Flask + Docker Compose | Пользователь умеет в Docker, нужен автозапуск и переживание перезагрузок |
| 5 | Токен хранится в `config.json`, файл в `.gitignore` | Секреты не должны попадать в git |
| 6 | Порт `5000`, слушает `0.0.0.0` | Только для локальной сети, **наружу не пробрасывать** |

## Отброшенные варианты

- **Cloudflare Tunnel + Yandex Dialogs** — требует домена и сложной настройки JSON-ответов. Отклонено: пользователь не хочет лишней сложности и плат.
- **Telegram-бот + Long Polling** — оставлен как **будущий** вариант для удалённого триггера извне. Не сейчас.

## Известные грабли (уже наступали)

- ⚠️ `https://yandex.ru/id/token` → **404**. Яндекс закрыл прямую страницу.
  Рабочий способ: OAuth-редирект через `get_token.py` (implicit flow, парсинг `access_token` из URL/fragment).
- ⚠️ Если в URL после редиректа нет `access_token` — пользователь скопировал не полный URL или не тот редирект.

## Что делать дальше (в этом порядке)

1. Разобраться с получением токена (текущая блокировка)
2. `docker-compose up -d` → `curl POST /api/tts` → убедиться, что Mini заговорила
3. Закрепить `station_id` в `config.json` (чтобы не бралась случайная первая колонка)
4. Ставить Home Assistant, подключить через `rest_command.alice_say`
